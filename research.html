Undergraduate Thesis

Development of a File Encryption and Hashing System

BSc Computer Science · Michael Okpara University of Agriculture, Umudike

Overview

Overview of the project:

This undergraduate research project focused on the development of a file encryption and hashing system designed to protect digital files against unauthorised access and help verify file integrity. The project explored the application of cryptographic techniques in securing stored files and detecting unauthorised modifications.

Research Objectives

  • Develop a system for encrypting and decrypting digital files.
  • Implement hashing techniques for file integrity verification.
  • Provide a means of protecting sensitive files against unauthorised access.
  • Evaluate the system's functionality and reliability.

Technical Focus

  • File encryption and decryption.
  • Cryptographic hashing.
  • Data confidentiality and integrity.
  • Secure file handling.

Research Outcomes

A functional file encryption and hashing system was developed, demonstrating the application of cryptographic techniques to file security and integrity verification.
